## 中文名称
视频资源下载器

## 英文名称
Video Resource Downloader

## 简短描述（中文）
一键抓取网页中的视频资源，支持直接下载、批量复制链接、自定义保存路径。

## 简短描述（英文）
One-click video resource capture from web pages. Supports direct download, batch copy URLs, and custom save paths.

## 详细描述（中文）

视频资源下载器是一款轻量级的 Microsoft Edge 浏览器扩展，帮助您快速抓取并下载网页中的视频资源。

### 主要功能

- **智能扫描**：自动检测页面中的 `<video>` 标签、`<source>` 标签及视频链接
- **网络拦截**：通过 webRequest API 捕获 JavaScript 动态加载的视频 URL
- **一键下载**：点击即可下载检测到的视频文件
- **批量复制**：支持一键复制所有视频链接
- **自定义路径**：可指定下载到 Downloads 下的子文件夹
- **流媒体识别**：自动标注 HLS (.m3u8) 和 DASH (.mpd) 流媒体

### 使用方法

1. 打开包含视频的网页
2. 如果视频是动态加载的，先播放几秒让视频开始缓冲
3. 点击工具栏上的扩展图标
4. 查看检测到的视频列表
5. 点击下载或复制链接

### 注意事项

- HLS/DASH/Blob 流媒体需要使用第三方工具（如 ffmpeg、yt-dlp）下载
- DRM 加密视频（如 Netflix、Disney+）无法下载
- 请尊重版权，仅下载您有权下载的视频内容

## 详细描述（英文）

Video Resource Downloader is a lightweight Microsoft Edge extension that helps you quickly capture and download video resources from web pages.

### Key Features

- **Smart Scanning**: Automatically detects `<video>` tags, `<source>` tags, and video links
- **Network Interception**: Captures dynamically loaded video URLs via webRequest API
- **One-Click Download**: Download detected video files with a single click
- **Batch Copy**: Copy all video URLs at once
- **Custom Save Path**: Specify subfolders under your Downloads directory
- **Stream Detection**: Automatically labels HLS (.m3u8) and DASH (.mpd) streams

### How to Use

1. Open a web page containing videos
2. If the video is dynamically loaded, play it for a few seconds first
3. Click the extension icon in the toolbar
4. Browse the detected video list
5. Click download or copy URLs

### Notes

- HLS/DASH/Blob streams require third-party tools (ffmpeg, yt-dlp) for downloading
- DRM-protected videos (Netflix, Disney+, etc.) cannot be downloaded
- Please respect copyright and only download content you have the right to

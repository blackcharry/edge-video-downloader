# 隐私政策

**最后更新：2026年5月28日**

## 概述

「视频资源下载器」扩展（以下简称"本扩展"）尊重并保护用户隐私。本隐私政策说明本扩展如何处理用户数据。

## 数据收集

**本扩展不收集、不存储、不上传任何用户数据。**

- 不收集个人信息（姓名、邮箱、地址等）
- 不上传浏览历史或下载记录
- 不使用第三方统计或追踪服务
- 不在服务器端存储任何用户数据

## 扩展权限说明

本扩展申请的浏览器权限及其用途：

| 权限 | 用途 |
|------|------|
| `activeTab` | 获取当前标签页信息以扫描视频资源 |
| `scripting` | 在页面中注入脚本以检测视频元素 |
| `downloads` | 将视频文件保存到您的本地下载文件夹 |
| `webRequest` | 拦截网络请求以捕获动态加载的视频 URL |
| `webNavigation` | 跟踪页面导航以刷新视频资源状态 |
| `storage` | 在本地存储您的下载路径偏好设置 |
| `host_permissions: <all_urls>` | 在所有网站中检测视频资源（仅限您主动打开的页面） |

## 数据存储

本扩展仅在您的本地浏览器中存储以下数据：

- **下载路径偏好**：您设置的自定义下载子文件夹名称（存储在浏览器本地 storage 中）

以上数据不会离开您的设备，不会发送到任何外部服务器。

## 第三方服务

本扩展不使用任何第三方分析、追踪或广告服务。

## 儿童隐私

本扩展不面向 13 岁以下儿童，不会有意收集儿童个人信息。

## 政策变更

本隐私政策如有更新，将在新版本发布时同步更新。
